# wargame

대한민국 **행정동을 실제 지도 영토로 사용하는 웹 기반 실시간 영역 점령 게임** 프로토타입입니다.

현재 게임은 현실의 군사 조직이나 무기 체계를 재현하지 않고, 행정동별 `병력 지수 / 보급 지수 / 인접 관계`만 사용하는 추상 전략 게임으로 설계되어 있습니다.

## 현재 구현

- React + TypeScript + Vite
- MapLibre GL JS
- OpenStreetMap 래스터 배경 지도

- 약 3,500개 행정동을 개별 게임 영토로 사용
- 공유 경계선 기반 인접 행정동 그래프 생성
- 도서 지역을 위한 추상 연결
- 시작 행정동 선택
- 플레이어 + 1~3개 AI 세력 선택
- 플레이어/AI 세력명 및 색상 사용자 지정
- 쉬움/보통/어려움 AI 난이도
- 실시간 틱, 일시정지, 1x/2x/4x
- 인접 영토 점령
- 행정동별 병력/보급 지수
- 공장 건설과 세력 자금 경제
- 자금으로 사단 편성 및 방어시설 강화
- 사단/보급/방어력 기반 점령 판정
- 인접 아군 행정동으로 1개 사단 지원 이동

- 전국 점령 승리 조건
- 줌인 시 행정동 이름 라벨
- 접경 영토 강조 및 전국 전황 막대
- 최근 점령/방어 이벤트 로그

- 반응형 웹 UI

## 지도 및 행정동 데이터

### OpenStreetMap

배경 지도는 OpenStreetMap 표준 타일을 사용합니다.

- Data © OpenStreetMap contributors
- https://www.openstreetmap.org/copyright

현재 표준 타일 서버는 개발 프로토타입 용도입니다. 공개 서비스 트래픽이 커지면 OSM 타일 사용 정책에 맞는 별도 타일 제공자 또는 자체 호스팅으로 교체해야 합니다.

### 대한민국 행정동 경계

행정동 폴리곤은 npm 패키지 `admdongkor`의 웹용 light 데이터를 사용합니다.

- 프로젝트: https://github.com/vuski/admdongkor
- 원자료: 통계청 SGIS 행정동 경계
- 데이터 라이선스: CC BY 4.0 / 공공누리 제1유형 출처표시
- 좌표계: light 데이터는 EPSG:4326

앱은 `admdongkor.versions()`의 최신 시점을 선택하고 `get(version, 'emd', { detail: false })`로 행정동 경계를 불러옵니다.

## 게임 인접성

행정동 폴리곤이 동일한 경계 선분을 공유하면 서로 인접한 영토로 처리합니다. 육상 경계가 없는 섬 권역 때문에 게임 그래프가 분리되는 경우, 각 분리 권역을 가장 가까운 본토 권역에 하나의 **추상 연결**로 이어 전국 점령이 가능하도록 합니다.


- 시작 자금: 320
- 공장 비용: 120
- 공장 1개 수익: 5틱마다 12

- 공격력은 사단 수와 보급의 영향을 받음
- 수비력은 사단 수, 보급, 방어시설 단계의 영향을 받음
- 점령된 영토의 공장은 남지만 방어시설은 일부 손상
- AI도 공장 수익을 받고 사단/공장/방어시설에 자금을 사용

## Division Overhaul

사단은 더 이상 영토에 붙은 단순 숫자가 아니라 개별 게임 엔티티입니다.

- 각 사단은 고유 ID, 사단명, 지휘관명, 현재 행정동을 가집니다.
- 병력 상태, 조직력, 보급, 경험, 전투력을 개별 추적합니다.
- 지도 위에 각 사단을 별도 토큰으로 시각화합니다.
- 같은 행정동의 여러 사단은 서로 겹치지 않도록 분산 표시합니다.
- 이동 중 사단은 현재 행정동과 다음 행정동 사이를 진행률에 따라 움직입니다.
- 선택한 사단의 이동 경로를 지도 위 점선으로 표시합니다.
- 지도 토큰 또는 사단 목록에서 사단을 선택할 수 있습니다.
- Shift/Ctrl/Command로 여러 사단을 동시에 선택할 수 있습니다.
- 선택 사단이 있을 때 지도 클릭은 실제 사단 이동 명령이 됩니다.
- 아군 영토를 따라 경로를 탐색하고 적 영토에 접촉하면 전투가 시작됩니다.
- 영토는 전투에서 승리한 사단이 실제로 진입한 뒤에만 점령됩니다.
- 패배 사단은 재정비하며 수비 사단은 가능한 경우 인접 아군 영토로 후퇴합니다.
- 사단 생산이 끝나면 생산 지역에 새로운 개별 사단이 배치됩니다.
- 사단명과 지휘관명을 UI에서 직접 수정할 수 있습니다.
- 기존 schema 1~6 저장은 영토별 사단 숫자를 개별 사단으로 자동 변환합니다.
- 새 schema 7은 사단 위치, 상태, 이동 명령, 전투 참가 상태까지 저장합니다.

### 기본 사단 조작

1. 하단 사단 메뉴 또는 지도 사단 토큰에서 사단을 선택합니다.
2. 여러 사단은 Shift/Ctrl/Command 선택으로 묶습니다.
3. 지도에서 목적 행정동을 클릭합니다.
4. 아군 영토면 이동하고 적 영토면 접촉 후 전투가 시작됩니다.
5. 전투에서 이긴 사단이 목표 영토에 들어간 뒤에만 점령됩니다.
6. Esc로 사단 선택을 해제하고 명령 바의 정지 버튼으로 이동 명령을 취소합니다.
