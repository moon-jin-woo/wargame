# wargame

대한민국 **행정동을 실제 지도 영토로 사용하는 웹 기반 실시간 영역 점령 게임** 프로토타입입니다.

현재 게임은 현실의 군사 조직이나 무기 체계를 재현하지 않고, 행정동별 `병력 지수 / 보급 지수 / 인접 관계`만 사용하는 추상 전략 게임으로 설계되어 있습니다.

## 현재 구현

- React + TypeScript + Vite
- MapLibre GL JS
- OpenStreetMap 래스터 배경 지도
- 최신 대한민국 행정동 경계 자동 로딩
- 약 3,500개 행정동을 개별 게임 영토로 사용
- 공유 경계선 기반 인접 행정동 그래프 생성
- 도서 지역을 위한 추상 연결
- 시작 행정동 선택
- 플레이어 + 1~3개 AI 세력 선택
- 플레이어/AI 세력명 및 색상 사용자 지정
- 쉬움/보통/어려움 AI 난이도
- 실시간 틱, 일시정지, 1x/2x/4x/10x
- 개별 사단 이동/전투/점령
- 행정동별 보급/산업/방어 상태
- 민수산업 / 군사산업 / 물류센터 / 인프라 / 연구시설의 5종 산업
- 산업 시설별 자금·생산·보급·이동·연구 효과
- 자금으로 산업 시설, 사단 편성 및 방어시설 강화
- 사단 전투력/조직력/경험/참호화/보급 기반 추상 전투 판정
- 자기 영토를 따라 다중 행정동 자동 경로 이동
- 아군 연결이 없는 고립 지역의 보급 감소
- 전국 점령 승리 조건
- 줌인 시 행정동 이름 라벨
- 접경 영토 강조 및 전국 전황 막대
- 최근 점령/방어 이벤트 로그
- 플레이어 전국 통계 요약
- 선택 지역의 시·도/시군구 점령률
- Space / 1·2·4·0 / F 키보드 단축키
- 행정동 이름/주소 검색
- 브라우저 저장/불러오기 + 10틱 자동 저장
- 반응형 웹 UI

## 지도 및 행정동 데이터

### OpenStreetMap

배경 지도는 OpenStreetMap 표준 타일을 사용합니다.

- Data © OpenStreetMap contributors
- https://www.openstreetmap.org/copyright

현재 표준 타일 서버는 개발 프로토타입 용도입니다. 공개 서비스 트래픽이 커지면 OSM 타일 사용 정책에 맞는 별도 타일 제공자 또는 자체 호스팅으로 교체해야 합니다.

### 대한민국 행정동 경계

행정동 폴리곤은 npm 패키지 `admdongkor`의 웹용 light 데이터를 사용합니다.

- 프로젝트: https://github.com/vuski/admdongkor
- 원자료: 통계청 SGIS 행정동 경계
- 데이터 라이선스: CC BY 4.0 / 공공누리 제1유형 출처표시
- 좌표계: light 데이터는 EPSG:4326

앱은 `admdongkor.versions()`의 최신 시점을 선택하고 `get(version, 'emd', { detail: false })`로 행정동 경계를 불러옵니다.

## 게임 인접성

행정동 폴리곤이 동일한 경계 선분을 공유하면 서로 인접한 영토로 처리합니다. 육상 경계가 없는 섬 권역 때문에 게임 그래프가 분리되는 경우, 각 분리 권역을 가장 가까운 본토 권역에 하나의 **추상 연결**로 이어 전국 점령이 가능하도록 합니다.

## 프로젝트 구조

```
src/
├── adminData.ts   # 행정동 다운로드, 중심점, 인접성 그래프
├── game.ts        # 게임 상태, 점령, AI, 틱
├── persistence.ts # 로컬 저장/복원
├── App.tsx        # MapLibre 지도와 UI
├── types.ts
├── main.tsx
└── styles.css
```

## 경제 / 군사 규칙

- 시작 자금: 320
- 공장 비용: 120
- 공장 1개 수익: 5틱마다 12
- 사단 편성 비용: 80
- 방어시설: 최대 4단계, 단계가 높아질수록 강화 비용 증가
- 공격 시 선택 영토 사단의 절반(올림)이 인접 영토 공격에 투입
- 공격력은 사단 수와 보급의 영향을 받음
- 수비력은 사단 수, 보급, 방어시설 단계의 영향을 받음
- 점령된 영토의 공장은 남지만 방어시설은 일부 손상
- AI도 공장 수익을 받고 사단/공장/방어시설에 자금을 사용

## Division Unit Overhaul

- 사단은 숫자가 아니라 개별 유닛 객체로 존재
- 각 사단은 고유 ID, 사단명, 지휘관, 전투력, 조직력, 경험치, 현재 위치를 가짐
- 지도 위 행정동별 부대 카운터로 사단 배치 시각화
- 사단 목록 및 개별 사단 선택
- 플레이어 사단명과 지휘관 이름 직접 수정
- 선택 사단의 이동/공격 경로를 지도 위 점선으로 표시
- 자기 영토를 따라 목적지까지 자동 경로 계산
- 아군 지역 클릭: 이동 명령
- 다른 세력 지역 클릭: 전선까지 이동 후 공격
- 영토는 사단이 실제로 진입하거나 전투에서 승리했을 때만 점령
- 같은 목표 전투에 여러 사단 증원 가능
- 전투 중 전투력/조직력/경험치 변화
- 수비 사단은 패배 시 인접 아군 지역으로 추상 후퇴 가능
- 사단 생산 완료 시 실제 신규 사단과 지휘관 생성
- 기존 숫자형 사단 세이브는 실제 사단 객체로 자동 마이그레이션

## Industry / Terrain Overhaul

- 산업을 5종으로 세분화
  - 민수산업: 주기 자금 수익
  - 군사산업: 사단 편성 및 회복 속도 보정
  - 물류센터: 지역 보급 회복과 고립 완화
  - 인프라: 건설 및 이동 시간 단축
  - 연구시설: 주기 연구점수 생성
- 국가 연구점수와 4개 추상 기술 트랙
  - 산업 공정
  - 물류 계획
  - 지휘 통신
  - 야전 공학
- 영토 / 보급 / 산업 / 지형의 4개 전략 지도 모드
- 지형을 도시 / 평야 / 구릉 / 산악 / 산림 / 해안 / 도서로 구분
- 지형이 이동 시간, 보급 회복, 공격·방어 보정에 반영
- 해안/도서 여부는 행정동 폴리곤 외곽 경계와 연결 컴포넌트로 근사
- 도시/평야/구릉/산악/산림은 행정동 명칭 및 폴리곤 규모 기반 근사 분류
- 실제 고도 DEM이나 토지피복 데이터가 아니므로 UI에서 "근사 지형"으로 표시
- 기존 schema 8 이하 세이브는 schema 9로 자동 마이그레이션
- 기존 공장 수는 민수산업으로 자동 이전
- 이동 명령 시 불필요한 전국 사단 수 재계산 제거
- 실제 위치가 바뀌는 틱에만 영토별 사단 수 재집계
- 보급 갱신 시 변화가 있는 영토만 새 객체로 생성
